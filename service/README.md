# HTTP-сервис

Прототип из ТЗ §6: веб-интерфейс, API с OpenAPI и хранилище галереи. Сервис работает поверх
того же ядра `vreid/`, тех же весов и того же замороженного рецепта `release/`, что и
конкурсный прогон, через адаптер `service/core.py`. Сходство, ре-ранжирование и порог отказа
он не пересчитывает и не меняет.

## Запуск

Весь стек — интерфейс, API, PostgreSQL с pgvector — из корня репозитория (`README.md`, раздел 1.1):

```bash
docker compose up --build             # http://localhost:8080
```

Отдельно, без контейнеров, с хранилищем SQLite:

```bash
python scripts/fetch_weights.py                                # release/model.pt
pip install -r requirements.txt -r requirements-service.txt    # torch/torchvision — под свою CUDA
python scripts/run_service.py --device cuda                    # или --device cpu
```

Открыть http://127.0.0.1:8765, Swagger UI — `/docs`. Модель загружается при первом извлечении
признаков. Галерея хранится в `var/service/gallery.sqlite3` и переживает перезапуск; другой
каталог — `--data-dir` или `VREID_SERVICE_DATA`, PostgreSQL с pgvector — строка подключения в
`VREID_DATABASE_URL`. `--release-dir` задаёт другой каталог с `model.pt` и `recipe.json`,
`--core-dir` — другой каталог с ядром.

Галерея привязана к отпечатку извлечения — весам и параметрам кропа (`crop_pad`,
`fast_decode`, `tta_flip`) — и к размерности вектора. Смена порога отказа сохранённые векторы
не обесценивает; смена весов или параметров кропа обесценивает, и сервис не запустится с
прежней галереей: нужен другой каталог данных или очистка (`docker compose down -v`).

## Что умеет

- Добавить одно наблюдение: кадр, рамка `xywh`, необязательный `image_id`.
- Импортировать ZIP: `test_gallery.csv` со столбцами `image_id,x,y,w,h` и каталог `images/`,
  имена файлов совпадают с `image_id`. Пакет записывается целиком после извлечения всех
  векторов или не записывается вовсе.
- Найти автомобиль по кадру: та же предобработка, модель, k-reciprocal и порог, что в
  конкурсном прогоне, один запрос против всей галереи. Десять кандидатов возвращаются всегда,
  в том числе при отказе; `accepted=false` и `candidate=null` означают отказ.
- Режим `?mode=ann` для больших галерей: HNSW-шортлист, затем тот же точный косинус. На
  галерее меньше 256 записей выполняется точный поиск, и ответ сообщает об этом в `notes`.
- Объяснить решение («Почему похоже»): точное разложение косинуса по участкам обоих кадров.
- Показать кадры и миниатюры автомобилей, список наблюдений, удалить наблюдение.
- Веб-интерфейс: вкладки «Поиск», «Галерея», «О системе»; работает без интернета. Кнопки
  демо-галереи и демонстрационного кадра по умолчанию выключены и включаются `VREID_DEMO_UI=1`.

Контракт: вектор 1536, рамка `xywh`, уверенность — сырой косинус, а не вероятность.

## HTTP

| Метод | Путь | Вход / результат |
|---|---|---|
| GET | /health | Состояние процесса, число записей, хранилище, отпечатки модели и рецепта |
| GET | /v1/model | Хэши, размерность, порог, устройство |
| GET | /v1/index/stats | Режим поиска и замеры ANN на галереях до 10⁶ |
| GET | /v1/gallery?offset=0&limit=100 | Список наблюдений |
| POST | /v1/gallery/items | multipart: image, bbox='[x,y,w,h]', image_id — необязательно |
| POST | /v1/gallery/import | multipart: archive — ZIP |
| GET | /v1/gallery/items/{id}/image | Исходный кадр; ?crop=true — миниатюра автомобиля |
| DELETE | /v1/gallery/items/{id} | Удаление наблюдения |
| POST | /v1/search?mode=exact\|ann | multipart: image, bbox, query_id — необязательно |
| POST | /v1/explain | multipart: image, bbox, gallery_id; ?regions=3 |

Полная спецификация — `/openapi.json`, интерактивно — `/docs`; подробности — `docs/API.md`.

Передавать `query_id`, если исходный кадр уже находится в галерее: он будет исключён из выдачи.
Для поиска нужны десять допустимых записей после исключения. Рамка должна находиться внутри
кадра.

Пример (локальный запуск; в стеке docker compose — порт 8080):

```text
curl -F "image=@query.jpg" -F "bbox=[100,100,400,200]" http://127.0.0.1:8765/v1/search
```

Ответ включает ranking, accepted, candidate, threshold, confidence_scale=raw_cosine,
gallery_count, search_mode, notes, хэши модели и рецепта и время запроса. Порядок ranking
может отличаться от сортировки по косинусу после ре-ранжирования.

## Ограничения

Один процесс и одна операция модели одновременно; конкурирующий запрос получает 503 с
Retry-After. До 1500 наблюдений в галерее, 20 МиБ и 40 Мпикс на кадр, 128 МиБ на ZIP. Импорт
синхронный; на CPU он может занять время. Галерея общая для экземпляра сервиса.

По умолчанию сервер слушает только localhost. Для адреса в локальной сети задать `VREID_API_KEY`
и передавать `X-API-Key`. Пользовательских ролей и распределённой очереди в этой версии нет.

## Проверка

```text
python -m pytest tests/service -q
```

HTTP-тесты используют тестовый кодировщик. Совпадение ответа сервиса с конкурсным прогоном
проверяет `tests/service/test_core.py` на настоящей сдаче; без весов и `submission/` тест
пропускается. Сквозная проверка на работающем сервисе —
`python scripts/smoke_backend.py --url http://localhost:8080`; ей нужен демо-набор, собранный
`scripts/make_demo_gallery.py`. Ни один из этих тестов не оценивает точность.
