# Цифровой отпечаток автомобиля

Идентификация транспортного средства по визуальным признакам, без опоры
на государственный регистрационный знак.

Система строит устойчивый признак автомобиля (тип кузова, геометрия, цвет,
повреждения, наклейки, диски, рейлинги, тонировка), связывает наблюдения
с разных камер и — если для части событий номер был известен — предлагает
кандидатов на сопоставление для кадров, где номер не читается.

## Чем отличается

Обычная система re-ID возвращает косинусное сходство и молчит о том,
насколько ему можно верить. Стоковый серебристый седан похож на каждый
второй стоковый серебристый седан, и число 0.87 в этой ситуации — выдумка.

Здесь система измеряет, **сколько информации она реально извлекла**,
и когда её мало — говорит об этом прямо:

- отпечаток измеряется в битах относительно размера автопарка;
- свидетельства локализованы и объяснимы («повреждение левого заднего
  крыла совпало», «эта зона не наблюдалась с обоих ракурсов»);
- выдача — ранжированный список кандидатов, никогда не один вердикт;
- ниже порога k-анонимности система отказывается сужать выдачу.

Последнее — не ограничение, а требование к системе, которой пользуются
в правоприменении: цена ложного срабатывания здесь — указание на невиновного.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
python -c "import torch; print(torch.cuda.get_device_capability())"   # (12, 0)
```

Данные — см. `docs/data.md`. В репозитории их нет.
