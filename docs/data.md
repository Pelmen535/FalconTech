# Данные

Тяжёлое в git не лежит (см. `.gitignore`). Здесь — где оно лежит на самом
деле, и как убедиться, что вы двое качаете одно и то же.

## Расположение

`DATA_ROOT` — переменная окружения, по умолчанию `./data`. Внутри:

```
data/
├── raw/                # исходники как получили, НЕ ТРОГАТЬ
├── crops/              # кропы машин, продукт src/ingest/
├── events/             # <camera_id>.jsonl
├── embeddings/         # .npy + ids.json
└── checkpoints/        # веса
```

`data/raw/` неприкосновенна. Любая обработка пишет в другое место —
иначе через неделю никто не вспомнит, что было в оригинале.

## Реестр датасетов

Контрольная сумма обязательна. Без неё «у меня работает, а у тебя нет»
занимает полдня.

| Датасет | Откуда | Размер | SHA-256 | Кто скачал | Дата |
|---|---|---|---|---|---|
| VeRi-776 | по запросу у авторов | — | — | — | — |
| VERI-Wild | по подписанному соглашению | — | — | — | — |
| данные организаторов | — | — | — | — | — |

```bash
# посчитать
sha256sum archive.zip
# проверить
echo "<sha256>  archive.zip" | sha256sum -c
```

## Сплит

Зафиксировать **один раз** и больше не трогать. Файл `configs/split.json`
со списками `event_id` — он в git, потому что маленький и критичен
для воспроизводимости.

Правило: одна машина целиком либо в train, либо в test. Сплит по кадрам —
запрещён (см. `docs/metrics.md`).
