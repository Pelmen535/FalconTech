## D-001. Берём в ядро четыре идеи

Дата: — · Автор: —

**Решили:** биты информации, граф номеров, исключение вместо поиска похожих,
k-анонимность по построению.

**Почему:** дёшевы, связны между собой, закрывают главные вопросы судей.

**Отвергли:** обучение ReID с нуля — за 15 дней гарантированный провал.
Отвергли также ставку только на точность модели — этим меряются все, и на
этом поле выигрывают вендоры с большими данными.

## D-002. Источник меток абстрагирован

Дата: — · Автор: —

**Решили:** `plate_of(event) -> str | None`, две реализации — реальный OCR
и симуляция из ground-truth с шумом распознавания.

**Почему:** на старте неизвестно, дадут ли организаторы данные. Архитектура
не должна этого ждать.

**Отвергли:** ждать данных и решать потом — потеря нескольких дней.
Отвергли также жёсткую привязку к OCR — делает проект незапускаемым
на публичных датасетах.

## D-003. UV-развёртка строится уровнями, L2 условен

Дата: — · Автор: —

**Решили:** L0 всегда, L1 почти всегда, L2 только при зелёных гейтах дня 2.
Контрольная точка дня 9: не работает end-to-end — убиваем, идём с L1.

**Почему:** высокая дисперсия. Каждый уровень самостоятельно защитим.

**Отвергли:** строить L2 сразу — если не взлетит, потеряны 4 дня без
запасного варианта.

## D-004. Развёртка всегда частичная

Дата: — · Автор: —

**Решили:** тройка `(T, M, Q)` на наблюдение, сравнение по `M_A * M_B`,
профиль — накопление по трекам и графу номеров.

**Почему:** с одного ракурса видно меньше половины поверхности. Площадь
пересечения масок — верхняя граница извлекаемой информации.

**Отвергли:** дозаполнять невидимое генеративно — выдумка, которая испортит
именно те признаки, ради которых всё делается.

## D-005. Зеркальная симметрия — гипотеза, не доказательство

Дата: — · Автор: —

**Решили:** зеркалирование разрешено для ранжирования, запрещено для
подтверждения и исключения.

**Почему:** вмятина на левой двери не повторяется на правой. Симметрия верна
для заводского слоя и ломается на отличительных признаках.

---

## D-006. Гейт качества позы

Дата: — · Автор: —

**Решили:** IoU растеризованного силуэта с сегментацией < 0.8 — наблюдение
выбрасывается целиком.

**Почему:** ошибка позы тихая: атлас выглядит правдоподобно, но признаки
уезжают. Кривые наблюдения не просто бесполезны — они портят накопленный
атлас профиля.

## D-007. Публичный репозиторий, данные вне git

Дата: — · Автор: —

**Решили:** код и документация в публичном GitHub, тяжёлое на облачном диске,
ссылки и контрольные суммы в `docs/data.md`.

**Почему:** публичный репозиторий снимает авторизацию у второго разработчика
и его ассистента.

**Отвергли:** хранить документацию на Яндекс/Гугл диске — нет диффов,
документ разъедется с кодом, конфликты решаются созданием «файл (2)».
