## Что воспроизведено без обучающей машины

- `scripts/fetch_weights.py` скачал `model.pt` из GitHub Release v1.2 и подтвердил
  SHA-256 из `release/weights.json`.
- На CPU выполнен полный `python -m vreid.predict` для двух синтетических query и
  десяти gallery. Получены `embeddings.npy` формы `(12, 1536)`, `submission.csv`,
  `candidates.csv` и `run_info.json`.
- `scripts/ci_offline_contract.py check` проверил порядок запросов, ровно десять
  разных кандидатов, сырые косинусы в `candidates.csv`, решение об отказе по
  косинусу фактически выбранного кандидата, L2-норму векторов и хэши входа,
  модели и рецепта. Проверка прошла.
- `scripts/ci_backend_contract.py` загрузил десять тех же изображений через
  FastAPI с настоящей моделью, нашёл оба query, сверил полный top-10 и отказ с
  конкурсным CLI, получил миниатюру и повторно открыл SQLite-галерею. Проверка
  прошла. Это подтверждает согласованность сервиса и конкурса на синтетическом
  наборе, а не качество поиска на реальных машинах.
- Локальный прогон выполнен с `PYTHONUTF8=1`. Без этой переменной консоль
  Windows с CP1251 падает при печати символа стрелки; в релизном Dockerfile
  `PYTHONUTF8=1` уже задан.

## Подтверждение в Linux CI

- [GitHub Actions, запуск №22](https://github.com/Pelmen535/FalconTech/actions/runs/35868809655):
  193 теста прошли, три пропущены; генератор синтетических CSV воспроизвёл
  закоммиченные файлы побайтово.
- Конкурсный образ собран с закреплёнными зависимостями и настоящими весами.
  При `--network none` он создал три обязательных файла; проверены порядок
  строк, top-10, сырые косинусы, отказ и хэши.
- Отдельный сервисный образ собран с `pip check`. API с настоящей моделью
  совпал с конкурсным CLI по полному top-10 и отказу; проверены миниатюра и
  сохранение галереи после перезапуска.
- Предыдущие красные запуски обнаружили реальный дефект ZIP-проверки на Linux,
  несовместимость Pydantic с базовым typing-extensions и несовпадение старых
  синтетических CSV с их генератором. Все три причины исправлены и покрыты
  зелёным запуском.
- Локально на Windows 183 проверки прошли по отдельным файлам, две
  пропущены; ещё 11 проверок ANN не дошли до запуска из-за конфликта двух
  OpenMP runtime в местном колесе Faiss. Полный набор теперь пройден в Linux CI.

## Отказ v1.2

Для опубликованного `results/refusal_stress_r392dw40.json` замороженный порог
`0.55` даёт `95.39` в сценарии с одно-камерными дублями и `67.68` без них.
Минимакс на сетке `0.01` — порог `0.47`, результаты `90.65` и `73.44`.
Вероятность безразличия между этими двумя порогами при смеси именно этих
сценариев равна `0.548`. Старое `0.913` внутри поля `threshold_choice` в
`release/recipe.json` относится к предыдущей модели. Рецепт опубликованного
релиза не переписан: изменение его SHA-256 требует нового версионированного
релиза и обновления манифеста. README и обзор исправлены как текущие пояснения.
